Wednesday 17th May 2006 - Updating the Format

Upon creating the initial skeleton of the website yesterday, today I decided that it needed some formatting and design added to the basic shell. Although I had a bit of a hunt around for some kits, I decided in the end to make a basic design and improve it as I go along. I also managed to add a counter** from a website. Although there are more complicated free downloads, I decided that to begin with I would just track the number of hits on the home page index.

Two other things I want to add is some sort of photo library and also a message board. I'll consider these over the next couple of days.

** Note that eventually this counter was removed, as we started using Google Analytics, which gives more detail, although this isn't visible to the end user. I anyone wants to know any stats about our hit rate, drop us a mail.
